# ResolveOps v1.4.0 — Employee IT live-agent workflow

Employee repository-access tickets now use the existing five-role Gemini graph through the normal
processing button when live mode is configured. Supervisor, investigation, policy, resolution and
critic outputs are persisted with token, tool and latency telemetry.

The agents remain advisory. The control plane validates the exact access-request ID, repository,
action type and approval requirement; separately enforces eligibility and the actual manager's
approval; executes an idempotent typed grant; and verifies directory, repository, ticket and
notification state with a fresh read. A mismatched or uncertain proposal stops for review.

Rules-only mode remains available when live inference is disabled. All public records and actions
are synthetic; no real Git host, identity provider, ticket system or email service is connected.
