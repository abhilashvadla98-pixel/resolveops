# ResolveOps v1.2.1 — Deployed live-agent workflow

This release records the flagship customer workflow running end to end on the public synthetic
sandbox. The normal **Investigate** action selected the bounded five-role Gemini graph, retained its
grounded trace, and handed the typed recommendation to deterministic controls. A separate simulated
human approval authorized one synthetic refund. Submission remained pending until a fresh provider
event and read confirmed settlement.

## Safety boundary

All customer, payment, return, refund and policy records are fictional. Model output is advisory.
Deterministic code validates cited evidence, policy and the typed action; a human approval is still
required; fresh state must confirm the final result. No live bank, CRM, directory or Git provider is
connected. The credential is not included in the repository, media or browser response.

## Honest limits

This is one observed successful deployed run, not an SLO or proof of general model reliability.
Cost is unknown because a verified provider price calculation was not captured. The requested
30-trial stochastic sample remains incomplete (one pass, one quota failure, 28 not run), and owner
human-review labels remain 0/24.
